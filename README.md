Tema: Minerando receitas: a busca por dados de medicamentos relacionados à saúde mental - Evolução do consumo de antidepressivos no Brasil entre 2015 e 2025

Abordagem(s) de coleta de dados: Datasets governamentais e Web scrapling no site do SUS (E-sus)

OpenDataSUS
